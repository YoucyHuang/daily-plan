# 经典主题素材出处

- `fern.webp` —— 森林「植物标本」里的蕨叶。
  出自 Thomas Moore 著、Henry Bradbury 自然印刷《The Ferns of Great Britain and Ireland》（1855），Plate XXIV *Lastrea dilatata*。
  原图：Biodiversity Heritage Library，https://www.biodiversitylibrary.org/pageimage/273765
  （Wikimedia Commons 同图：https://commons.wikimedia.org/wiki/File:The_ferns_of_Great_Britain_and_Ireland_(Plate_XXIV)_BHL273765.jpg ）
  授权：公有领域（Public domain，1855 年出版）。处理：抠出主叶、去纸色转透明、缩到 599×1384。

其余（罗经花、浪纹、瓶罐、稿纸格、月相、星空）都是代码里用 SVG / CSS 画的，没有外部素材。
